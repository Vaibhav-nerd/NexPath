# Career Roadmap Generator (MERN)

Reverse-engineered career roadmap generator powered by Anthropic Messages API, Express, and React Flow.

## Setup & Running
1. `copy .env.example .env` and set `ANTHROPIC_API_KEY` & `MONGODB_URI` (or leave `LLM_MOCK=true` for testing).
2. Install & start backend: `cd server && npm install && npm run dev`
3. Install & start frontend: `cd client && npm install && npm run dev`
4. Open frontend at `http://localhost:5173`.
5. Run tests: `cd server && npm test`.
