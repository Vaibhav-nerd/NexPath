# How to Import into Figma

The vector design file [`career-roadmap-design.svg`](file:///d:/New%20folder/career-roadmap-design.svg) has been created at the root of your workspace.

### Steps to Import:
1. Open [Figma](https://www.figma.com/) (Desktop App or Web).
2. Open any Figma design file or draft.
3. Simply **drag and drop** `career-roadmap-design.svg` from your file explorer onto the Figma canvas (or click **File → Place Image... / Import**).
4. Figma will automatically convert every group into editable vector layers and frames:
   - **Artboard 1: Desktop Canvas (1440 × 900)**: Complete UI with 64px Query Bar, Dagre Graph Canvas, connected nodes, minimap, controls, and 360px Slide-out Side Panel.
   - **Artboard 2: Mobile View (375 × 812)**: Mobile layout with 70vh bottom sheet overlay.
   - **Artboard 3: Design System & Tokens**: Color palette swatches, typography scale, node kinds (`skill`, `project`, `cert`, `milestone`, `done`), interactive controls, and UX states.
